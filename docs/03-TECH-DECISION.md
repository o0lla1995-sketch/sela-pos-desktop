# قرار تقني معماري (ADR-001): Tauri 2 + React/TypeScript + نواة Rust

## القرار
بناء سطح المكتب بـ **Tauri 2** (واجهة React 18 + TypeScript عبر Vite) مع **نواة Rust** (`sela-core`)
تملك قاعدة البيانات والعتاد، وصندوق أعمال `src-tauri` رقيق يكشفها كأوامر.

## المبررات الهندسية
1. **تطابق المنطق بأقل مخاطرة**: منطق sela التجاري كله TypeScript خالص (تسعير الوحدات، حرس
   البيع الزائد، ترقيم الفواتير، توقيع Ed25519، قوالب الفاتورة، تنسيق الأموال) — منقول
   **حرفياً** إلى الواجهة نفسها، ويعاد إثبات التطابق باختبارات نفس المدخلات على جانبي
   JS/Rust. إعادة كتابة بـ C#/WPF أو Flutter تعني إعادة تنفيذ ~4000 سطر يدوياً بلغة أخرى —
   أعلى احتمالاً للانحراف عن سلوك الأندرويد.
2. **العتاد الأصلي**: طباعة ESC/POS الخام تحتاج مقابس TCP خام، منافذ COM، كتابة Spooler RAW،
   وخطاف لوحة مفاتيح عام WH_KEYBOARD_LL — كلها قوىّ أولى في Rust بثنائيات صغيرة، بينما
   تحتاج Electron وحدات native هشة (node-serialport/node-printer) وتُجرّ مثقلاً بـ Chromium.
3. **خفة وكفاءة (شرط المهمة)**: Tauri يستخدم WebView2 الموجود في ويندوز 10/11 — مثبّت
   ~10–15MB وذاكرة ~80MB مقابل ~200MB+ و~300MB لـ Electron. المهمة نصّت: «خفيف، عالي
   الكفاءة، ملف تنفيذي نقي».
4. **SQLite مضمّنة بلا خدمة**: rusqlite مضمّنة (embedded) — لا خادم ولا تثبيت، مخطط مطابق
   حرفياً لقاعدة الأندرويد، والنسخ الاحتياطي JSON v1 نفسه هو جسر الهجرة أندرويد→مكتب.
5. **خط تجميع مُجرَّب**: GitHub Actions على `windows-latest` يخرج NSIS مثبّتاً + exe محمول
   موقّعاً بنفس تدفق الوسوم الذي أنتج 60+ إصداراً من تطبيق الأندرويد — بلا أي تجميع
   متقاطع محلي هش.

## البدائل المرفوضة
- **Electron**: كفاءة/حجم مرفوضان أعلاه؛ وحدات الطباعة التسلسلية native أقل استقراراً.
- **C# WPF/MAUI**: أعلى كلفة تطابق (إعادة كتابة كل المنطق) بلا مكسب عتادي إضافي يذكر.
- **Flutter Desktop**: إعادة كتابة بلغة ثالثة + نضج طباعة/تسلسلي على ويندوز أقل.

## حدود القرار المخاطرة
- لا يمكن تجميع واجهة Tauri محلياً على لينكس هنا (لا webkit2gtk) — لذلك النواة `sela-core`
  مكتبة مستقلة **تُختبر محلياً بالكامل** (cargo test)، والواجهة تُفحص بـ tsc/vite/vitest،
  والتجميع الكامل يقع على `windows-luster` في CI — نفس نمط الجولات 60+ السابقة مع APK.
- أجزاء ويندوز الصرفة (WinSpool/الخطاف) خلف `#[cfg(windows)]` — تُترجم وتُختبر في CI،
  بينما قناوَا TCP/التسلسلي تعمل وتُختبر محلياً على لينكس (طباعة حقيقية إلى طابعة TCP
  عبر الشبكة متطابقة السلوك بين المنصتين).

## حدود واجهة React
- صفر مكتبات UI خارجية: React + zustand + tweetnacl فقط — CSS يدوي بنفس هوية sela
  الداكنة (خلفية `#0D0D0F`، سطوح `#17171A`، حدود `#2A2A2A`، برتقالي العلامة `#EA580C`).
- RTL كامل `dir="rtl"`، خطوط النظام العربية، تخطيط أفقي ثابت (شبكة/يسار + سلة/يمين).
