# شجرة ميزات تطبيق sela الأندرويد (v6.0.0) — المصدر الوحيد للحقيقة للتحويل

> استُخرجت بالمسح المباشر لمصدر `/home/z/my-project/SmartVisionPos` (الجذر `3f574d4`).
> كل بند هنا يجب أن يظهر بنفس السلوك في نسخة سطح المكتب — لا استثناءات.

## 1) بوابة الترخيص والاشتراك (LicenseService)
- تفعيل مفتاح من سيرفر الإدارة `POST /api/v1/activate` `{key, deviceId, deviceLabel, appVersion}`.
- رخص موقّعة **Ed25519** (tweetnacl) وتتحقق محلياً بالمفتاح العام المخبوز في البناء.
- نبضة تحقق `POST /api/v1/heartbeat` + فك ارتباط `POST /api/v1/unbind` + `GET /api/v1/config`.
- **زمن موثوق** ضد عبث الساعة: مرساة `serverTime + uptime أحادي التصاعد` + رصد إرجاع الساعة (ضربات تلاعب، القفل عند 5).
- حالات البوابة: `needs_activation / active / grace / locked` — سماح دون سيرفر: 72 ساعة (تحذير) ثم قفل عند 240 ساعة.
- الأخطاء العربية المعروفة للمستخدم (INVALID_KEY / KEY_REVOKED / DEVICE_LIMIT / …).

## 2) شاشة الكاشير (PosScreen)
- شبكة منتجات (3 أعمدة بالهاتف) + بحث نصي فوري.
- مسح: باركود + بصري (كاميرا/tflite) — **بالنسخة المكتبية يُستبدل بقارئ HID خارجي (المهمة §2.أ)**.
- سلة: سطر لكل (منتج × وحدة) بسعر حسب وضع التسعير (مفرق/جملة)، خصم مطلق على الفاتورة.
- **حرس البيع الزائد**: الحد بالمخزون يُحسب دائماً بوحدات أساس (`qty × conversion`) عبر `baseUsed()`.
- إتمام البيع → `SaleRepo.createSale` داخل **معاملة واحدة**: insert sale + items + `UPDATE … WHERE stock_quantity >= ?` (فشل = رسالة عربية والسلة سليمة).
- ترقيم الفواتير `INV-YYYYMMDD-NNNN` بمعدّاد يومي دائم (MMKV).
- مسودة السلة تُحفظ لحظياً (MMKV) — لا خسارة عند قتل التطبيق.

## 3) الطباعة الحرارية (ESC/POS)
- بانية عمليات: `init / codepage / align / bold / size / text / feed / cut / rawBase64 / image`.
- قالب الفاتورة: شعار (raster مركز) → ترويسة المتجر (غامق مضاعف) → هاتف → رقم الفاتورة/التاريخ/وضع الدفع → بنود (اسم عربي سطر + سطر أموال ASCII `qty x price = total`) → إجماليات (Subtotal/Discount/TOTAL) → ربح صافي (اختياري للمدير) → تذييل + شكراً → feed + قص.
- صفحة كشف الحروف العربية `CP1256 (47)` أو `CP864 (45)`، عرض 58مم (32 حرفاً) أو 80مم (48).
- طباعة تجريبية من الإعدادات.

## 4) المخزون والكتالوج
- منتجات: `cost/retail/wholesale`، مخزون، تصنيف، حد تنبيه خاصة، باركود، صورة.
- وحدات البيع: `product_units` (معامل تحويل + باركود كرتونة + تجاوزات أسعار مفرق/جملة).
- إدارة التصنيفات (بذر 6 تصنيفات عربية أول تشغيل) وإدارة الوحدات (بذر 10 وحدات).
- تنبيهات النقص: حد عام + حد لكل منتج، دفتر (`ledger`) يمنع تكرار التنبيه.

## 5) الجرد (Stocktakes)
- جلسة `open` تجمّد `system_qty` لكل منتج → عدّ `counted_qty` → إقفال.
- الإقفال مع «تطبيق الفروقات» = `UPDATE products SET stock_quantity = counted` لكل المعدود فقط (معاملة واحدة)، أو إقفال بلا تعديل.
- ملخص: عدد البنود/المطابق/عجز/زيادة/إجمالي النظامي/الفعلي.

## 6) التقارير
- نطاقات: اليوم/أمس/آخر 7/هذا الشهر/مخصص.
- الملخص: إيراد، تكلفة (cogs)، ربح صافي، عدد فواتير، عدد أصناف، إجمالي خصومات، متوسط فاتورة.
- الأعلى مبيعاً (بمنتج)، منحنى يومي (إيراد/ربح)، ساعات الذروة.
- **created_at بتوقيت المتجر المحلي دائماً** (لا UTC) — نفس القاعدة في النسخة المكتبية.

## 7) سجل الفواتير
- آخر الفواتير + إعادة فتح تفاصيل + **إعادة طباعة** بنفس قالب الفاتورة من التاريخ.

## 8) الإعدادات
- بيانات المتجر (اسم/هاتف/عنوان/تذييل/شعار)، وضع الماسح، متغيرات البصمة، إعدادات الفاتورة (عرض/codepage/إظهار الربح)، اقتران طابعة، تنبيهات النقص، الوضع الداكن/الفاتح.
- نسخ احتياطي JSON **v1** (`app:"sela"`) يحمل كل شيء + استعادة ذرّية بمعاملة واحدة وترقيم هويات جديد.
- مسح كل البيانات، Diagnostics (سجل حلقي)، نبذة + إصدار.

## 9) مركز الإشعارات داخل التطبيق
- أنواع: نفاد/نقص/معلومة/طابعة/بيع/جرد — مع عدّاد غير المقروء.

## 10) خارج نطاق التطابق (غير موجودة في الأندرويد → لا تُبنى)
- مستخدمون وصلاحيات، عملاء/موردون/ديون، Z-Report/إقفال وردية، ضريبة VAT، مرتجعات.
- البصري/الكاميرا على المكتب: **محظور بموجب المهمة §2.أ** — بصمات المنتجات تبقى في القاعدة والنسخة الاحتياطية (توافق بيانات) دون أي مسح بصري.

## 11) إضافات سطح المكتب (خارج التطابق، مكتبية فقط)
- خادم «سيلّا كاشير» LAN (v58): شاشة الكاشير + صلاحيات + تقرير + QR اتصال.
- **أيقونة شريط المهام + الاستمرار بالخلفية (v68)**: إغلاق النافذة مع خادم الكاشير
  يعمل يخفيها بدل إيقاف الخادم — البرنامج يبقى حياً من أيقونة سيلا في شريط المهام
  (نقرة يسار = فتح النافذة، قائمة يمين = إنهاء كامل). الإعداد «الاستمرار بالخلفية
  بعد إغلاق النافذة» في شاشة الكاشير (مفعّل افتراضياً). إشعارات نظام ويندوز عبر
  Web Notification API (WebView2) بينما البرنامج بالخلفية — الإذن يُطلب عند تشغيل
  الخادم. فتح البرنامج من الاختصار أثناء العمل بالخلفية يُظهر النافذة (مثيل واحد).
