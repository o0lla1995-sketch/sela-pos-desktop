## قرارات العتاد المكتبي (المهمة §2)
- **مستمع الباركود العام**: `WH_KEYBOARD_LL` (windows) يجمع الاندفاعات ويبثّ `barcode://payload` عبر أحداث Tauri بغضّ النظر عن التركيز؛ يوجَّه إلى: شاشة الكاشير (إضافة/بحث) أو حقل البحث العام. حاجب (debounce) 1.6s لنفس الكود — نفس `BARCODE_DEDUPE_MS`.
- **الطباعة الصامتة**: لا حوارات ويندوز — كتابة بايت خام إلى القناة المختارة. عند غياب الطابعة: رسالة عربية + إعادة محاولة يدوية (اختبار إجهاد §5.3).
- **درج النقدية**: `ESC @ d … (m t)` بمقابس RJ11 عبر الطابعة نفسها — اختياري «عند كل بيع» أو يدوي.
- **مداخل القنوات**: TCP `host:port`، تسلسلي `COMx@baud`، WinSpool `اسم الطابعة المثبتة` — قائمة المنافذ التسلسلية والطابعات المثبتة تُجلب من النظام.
