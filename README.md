## الميزات (تطابق أندرويد v57)
- **البيع**: نقدي/دين صِلة (INV-D)/دين المتجر (INV-L)/طلبات أونلاين
  (INV-O)/قسائم (INV-V) + خصم منتج (v51) وخصم فاتورة + متغيرات
  الملابس والأحجام (v35) + منتجات الوزن (v8.3) + مخزون بلا تتبع.
- **المرتجعات (v23/v40)**: سجل RET مستقل، استرداد نقدي أو تسوية دين،
  الاستبدال بقيمة المرتجع، returned_minor على الفاتورة الأصلية.
- **الخزينة (v25)**: مصروف/سحب/إيداع بسندات فريدة، حماية PIN، معادلة
  النقد المتوقع، كشف فترة حراري + تصدير HTML للطباعة/PDF.
- **صِلة (v11→v22)**: اقتران التاجر، طابور ديون وسدادّات بالمزامنة
  الذاتية (idempotency)، أرصدة مفصولة الأصول، تحصيلات التطبيق،
  قسائم الحملات (تفعيل/صرف/تسويات/مستحقات).
- **البيع أونلاين (v48→v56)**: ملف المتجر ومناطق التوصيل، مزامنة
  كتالوج وصور (v49)، إدراج انتقائي (v55)، دورة طلبات كاملة
  (قبول→إرسال INV-O→تسليم COLL→إرجاع RFD)، منتجات النقطة (v56).
- **الأمان (v27)**: قفل التطوق برمز PIN + مهلة خمول.
- **الجرد**: بصفوف متغيرات الملابس (v38) + تسوية قيمة بالتكلفة.
- **النسخ الاحتياطي**: JSON v2 بنفس تنسيق الهاتف (استيراد/تصدير
  بين الجهازين) + نسخ تلقائي لمجلد.

## العتاد
- **باركود/QR**: قارئ USB/بلوتوث HID — مستمع عام على مستوى النظام
  (اندفاعة <50مللي، ≥4 خانات، Enter) يعمل دون تركيز أي حقل؛ الرموز
  تُفهم تلقائياً: منتج/وحدة، بطاقة صِلة، دفع آجل، أو قسيمة حملة.
- **طباعة حرارية**: TCP 9100 / تسلسلي COM / WinSpool RAW (USB) —
  إيصالات البيع/الدين/المرتجع/القسيمة/سندات الخزينة + ملصقات
  EAN-13/CODE128 (GS k) + شعار raster — CP1256/CP864 صامتة بلا حوارات.
- **درج النقدية**: نبضة ESC p عند كل بيع (اختياري) أو يدوياً.
- **الكاميرا**: خارج نطاق سطح المكتب — المسح البصري للهاتف فقط.

## خادم الكاشير (سيلّا كاشير) — v58→v69
- **الشبكة المحلية**: شغّل الخادم من شاشة «الكاشير» (المنفذ الافتراضي
  8950) — تطبيق «سيلّا كاشير» على الهاتف يجد متجرك تلقائياً أو بمسح
  رمز QR. كل بيع/مرتجع/دين يسجَّل لحظياً باسم الكاشير في الفواتير
  والخزينة والمخزون.
- **الاستمرار بالخلفية (v68)**: إغلاق النافذة مع خادم يعمل يخفيها
  لأيقونة شريط المهام — الخادم لا يتوقف. الخروج الكامل من قائمة
  الأيقونة.
- **التشغيل التلقائي مع ويندوز (v69)**: عند تشغيل الخادم يُفتح مفتاح
  إقلاع تلقائي (HKCU Run) — بعد أي إعادة تشغيل للجهاز يبدأ سيلا
  بالخلفية (بلا نافذة) ويشتغل الخادم وحده. قابل للإلغاء من صفّه في
  شاشة الكاشير.
- **الاتصال عن بُعد — Tailscale/VPN (v69)**: شاشة الكاشير تعرض **كل**
  عناوين الجهاز (شبكة المحل + عنوان 100.x الخاص بـTailscale). شغّل
  Tailscale على الجهاز والهاتف بنفس الحساب ثم أدخل عنوان 100.x في
  تطبيق الكاشير («إدخال يدوي») — يعمل من أي مكان.
- **ملاحظة جدار الحماية**: محوّل Tailscale يصنَّفه ويندوز «شبكة عامة»،
  فقاعدة السماح الاعتيادية («الشبكات الخاصة» فقط) تحجب الاتصال عن
  بُعد رغم فتح المنفذ يدوياً. **المثبّت (v69)** يضيف قواعد المنفذ
  8950/8951 والبرنامج لكل ملفات التعريف تلقائياً، ولتثبيت قديم يوجد
  زر «فتح المنفذ الآن» في شاشة الكاشير (موافقة ويندوز مرة واحدة).

## الهجرة من الأندرويد
ملف النسخة الاحتياطية JSON نفسه (`app:"sela"`, backupVersion 2) —
صدّره من الهاتف واستورده هنا (والعكس): الكتالوج بالمتغيرات والوحدات
والخصومات، الفواتير بكل سلاسلها (INV/INV-D/INV-L/INV-O/INV-V/RET)،
الديون والسدادّات، حركات الخزينة، الطلبات الأونلاين، والإعدادات.
