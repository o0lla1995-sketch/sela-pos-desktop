# سيلا POS — سطح المكتب (Sela POS Desktop)

تحويل كامل لتطبيق نقاط البيع **sela** (أندرويد v6.0.0) إلى نظام سطح مكتب
خفيف عالي الكفاءة لويندوز — **تطابق 100%** في الميزات والمنطق التجاري
وحالات الاستخدام، مع استبدال عتادي كامل (المهمة §2).

## البنية
```
crates/sela-core/   نواة Rust: القاعدة (نفس DDL أندرويد) + معاملات البيع
                    + التقارير + الجرد + النسخ v1 + ترميز ESC/POS بايتاً ببايت
src-tauri/          صندوق رفيع: أوامر Tauri + خطاف الماسح WH_KEYBOARD_LL
src/                واجهة React+TS: منطق الأندرويد منقول حرفياً (TS خالص)
docs/               المرحلة الأولى: شجرة الميزات + مصفوفة الاستبدال + ADR + المخطط
```

## العتاد (§2)
- **باركود/QR**: قارئ USB/بلوتوث HID — مستمع عام على مستوى النظام
  (اندفاعة <50مللي، ≥4 خانات، Enter) يعمل دون تركيز أي حقل.
- **طباعة حرارية**: TCP 9100 / تسلسلي COM / WinSpool RAW (USB) — صامتة
  بلا حوارات، CP1256/CP864، قص تلقائي، شعار raster، ملصقات CODE128،
  وQR اختياري بالفاتورة.
- **درج النقدية**: نبضة ESC p عند كل بيع (اختياري) أو يدوياً.
- **الكاميرا**: محظورة بموجب المهمة — لا مسح بصري على المكتب إطلاقاً.

## الهجرة من أندرويد
ملف النسخة الاحتياطية JSON v1 نفسه (`app:"sela"`) — صدّرها من هاتفك
واستوردها هنا (والعكس). الإعدادات والفواتير والجرد والوحدات كلها تنتقل.

## التشغيل
```bash
npm install
npm run tauri dev      # تطوير
npm run test           # اختبارات التكافؤ (13 واجهة + 29 نواة)
npx tauri build        # .exe + مثبّت NSIS
```

## الاختصارات (§3.1)
F2 بحث · F3 مفرق/جملة · F4 خصم · **F9 إتمام البيع** · Del حذف السطر المحدد ·
+/− كمية المحدد · Esc إلغاء التحديد. المسح العام يعمل من أي شاشة.

## المسارات
`%AppData%\sela-pos\` — `sela.db` (SQLite، نفس مخطط الأندرويد) +
`config.json` (نفس مفاتيح MMKV بأسمائها) + `assets/`.
